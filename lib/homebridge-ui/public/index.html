Shellys and Matter devices

The hardware this plugin reads. What each one measures shows with its appliance, or under Appliances → Found, not set up yet.

Asks every address on the Homebridge computer's home network; takes about 10 seconds.
+ Add a Shelly
Any Wi-Fi Shelly that measures power or switches: Gen1, Gen2, Gen3 and Gen4 (also ones paired to Apple Home over Matter), and ones with the HomeKit firmware: plugs, relays, dimmers, shutter controllers and EM meters, by their address on your home network. Shellys with a password set can't be read.
+ Add a Matter device
In the Home app: the device's (or its bridge's) settings → Turn On Pairing Mode, then copy the code here. It stays in Apple Home; this plugin joins as a second controller and only reads it.
